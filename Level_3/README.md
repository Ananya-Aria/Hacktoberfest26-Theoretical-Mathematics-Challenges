# Level 3: Bend

Each task gives you a method that already works. Then **one rule changes**. Your job is to work out how the method has to change, and what that does to the answer.

You need your **Enigma number E** (see the [main README](../README.md#your-enigma-number-e)). The examples use E = 4671, from the username `math-cat7`.

## The tasks

Each task has its own folder. Submit each task as **its own pull request**, with your work in `Level_3/<task-folder>/<your-github-username>/`. Any format is fine: a `solution.md`, a scanned PDF of handwritten pages, or photos.

| Task                                   | Folder                                      |
| -------------------------------------- | ------------------------------------------- |
| 3A: The maze where you may break walls | [A_maze](A_maze/README.md)                   |
| 3B: Tower of Hanoi with a broken peg   | [B_hanoi](B_hanoi/README.md)                 |
| 3C: Fair matching                      | [C_fair_matching](C_fair_matching/README.md) |

Do at least two of the three tasks; all three is better.
