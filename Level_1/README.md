# Level 1: Observe

In this level you try small cases by hand, spot a pattern, and explain **why** it happens. No coding is needed. Pen and paper are enough.

Every task starts with a **guess**. Write it down before you work anything out. Being wrong is fine.

You need your **Enigma number E** (see the [main README](../README.md#your-enigma-number-e)). The examples below use E = 4671, from the username `math-cat7`.

## The tasks

Each task has its own folder. Submit each task as **its own pull request**, with your work in `Level_1/<task-folder>/<your-github-username>/`. Any format is fine: a `solution.md`, a scanned PDF of handwritten pages, or photos.

| Task                         | Folder                                      |
| ---------------------------- | ------------------------------------------- |
| 1A: The bridges of your city | [A_city](A_city/README.md)                   |
| 1B: Find the fake coin       | [B_fake_coin](B_fake_coin/README.md)         |
| 1C: The slowest GCD          | [C_CForChocolate](C_CForChocolate/README.md) |

Do at least two of the three tasks; all three is better.
